AMAN TRADERS WEBSITE

Files:
- index.html: website structure
- style.css: responsive design and styling
- script.js: product filters and WhatsApp enquiry actions
- assets/shop-interior.png: generated paint-shop interior image

Preview:
Extract the ZIP and open index.html in your browser.

Publish with GitHub Pages:
1. Create a public repository named Aman-Traders.
2. Upload index.html, style.css, script.js, README.txt, and the complete assets folder.
3. Open Settings > Pages.
4. Choose Deploy from a branch, select main and /(root), then Save.
5. Wait for deployment; the live URL will appear on the Pages screen.

WhatsApp:
The website uses Indian WhatsApp number 918318001646.
- Direct WhatsApp buttons open the chat.
- Product/brand buttons open WhatsApp with a suggested enquiry.
- The enquiry form builds a message using the entered details and opens WhatsApp.
- The customer reviews and sends the message manually.

Image:
The included shop image is a generated paint-shop interior image, not a verified photograph of the actual Aman Traders store.

This is a static site; it does not store enquiry data or show live prices/stock.
